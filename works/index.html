Piano HTML CSS JavaScript

作品名: 自動演奏ピアノアプリ

手動演奏機能と自動演奏機能をもつ簡易的なピアノアプリです。

制作目的

関数・DOM操作・イベントリスナー・タイマーIDなどJavaScriptの基礎内容について学習し、学習内容の定着および応用として、自動演奏機能のついたピアノアプリを制作しました。

工夫した点

本物のピアノを弾いている感覚を味わってもらうため、グランドピアノをイメージしたデザインにし、ピアノ音源を使用しました。

ピアノ経験者も、初めてピアノを演奏する人も安心してお使いいただけるよう、鍵盤の音名表示 ON / OFF を常に切り替えられるようになっています。また、鳴っている音の鍵盤がハイライトするようになっているので、指使いを学習する目的でもお使いいただけます。

操作方法

  1. 手動演奏機能

    鍵盤を押すと音が鳴り、鳴っている音が画面上部の音名表示エリアに表示されます。

  2. 自動演奏機能

    「自動演奏」ボタンを押すと、収録されている楽曲の中から1曲をランダムに選択し、自動で演奏します。自動演奏は「演奏中止」ボタンを押すか最後まで演奏されると止まります。

制作目的

工夫した点

Sports Club Handstone EC Site HTML CSS JavaScript PHP MySQL

作品名: Sports Club Handstone EC Site

架空のプロテイン専門販売サイトです。

  • ログインページ
  • 新規登録ページ
  • 商品管理ページ
  • 商品一覧ページ
  • ショッピングカートページ
  • 購入完了ページ

で構成されています。

制作目的

POSTメソッド、画像アップロード、セッション、Cookie、関数、PDO接続などPHPとSQLの基礎内容について学習し、学習内容の定着および応用として、ECサイトを制作しました。

工夫した点

遊び心こだわり満載の商品ラインナップで、SNSでバズること間違いなし！？

クーポンコード入力による割引機能、商品検索機能、カート内の商品数が一目で分かる購入バッジなど、ユーザー目線で欲しい機能を盛り込んでいます。

加えて、フォームの二重バリデーション、ログイン時のセッション再発行、SQLインジェクション対策、XSS対策、パスワードハッシュ化、CSRFトークンなどのセキュリティ対策を施しています。さらに悲観的ロックによる排他制御によりデータの整合性を保てるようにも設計されています。

私のイチ押し商品は「桃色♡肩重い」味！

利用方法

  1. 新規登録・ログイン

    「新規登録」ページにて任意のユーザーIDとパスワードを登録しユーザー登録を行います。

  2. 商品の閲覧

    気になる商品がありましたら、「カートに入れる」ボタンを押してカートに入れてみましょう。

  3. 購入手続き

    「購入する」ボタンを押すと、購入が完了します。
    ※ 架空サイトのため、実際に金銭が発生することはありません。

    クーポンコードを入力すると、1ユーザーにつき1回のみ割引を適用することができます。

    • SHIMAMOTO: ¥1,000OFF
    • HANDSTONE: ¥1,000OFF
    • ほか、その月のクーポン(詳しくはサイト内で案内しています)を使用することができます。

Communication Game Apps HTML CSS JavaScript

作品名: Communication Game Apps

「コミュニケーション」×「ゲーム」をコンセプトに、利用者間の交流・親睦を深めるイベントを毎週行っています。実施したイベントのうち、特に人気のあったものを数種類ピックアップしました。

制作目的

有志活動としてコミュニケーションゲームの企画・運営を行っています。UI Dictionary(上述)の制作経験を経て、「自身が制作したものを通じて、より多くの利用者に充実した参加体験を提供したい」という気持ちが強くなり、簡易的なWebアプリの制作を始めました。

工夫した点

ゲームの企画においては単に面白いゲームを行うのではなく、「コミュニケーション」と「ゲーム」それぞれの主目的を置くことを軸とし、「面白くてためになる」ものを目指しました。

コーディングにおいても単に「動くものをつくる」のではなく「将来の自分と有志を担う人が安心して触れるものをつくる」ことを目的とし、可読性・保守性・拡張性を意識したコーディングを心がけました。
