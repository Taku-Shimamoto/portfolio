Piano HTML CSS JavaScript

作品名: 自動演奏ピアノアプリ

手動演奏機能と自動演奏機能をもつ簡易的なピアノアプリです。

制作目的

関数・DOM操作・イベントリスナー・タイマーIDについて学習し、学習内容の定着および応用として、自動演奏機能のついたピアノアプリを制作しました。

工夫した点

本物のピアノを弾いている感覚を味わってもらうため、グランドピアノをイメージしたデザインにし、ピアノ音源を使用しました。

ピアノ経験者も、初めてピアノを演奏する人も安心してお使いいただけるよう、鍵盤の音名表示 ON / OFF を常に切り替えられるようになっています。また、鳴っている音の鍵盤がハイライトするようになっているので、指使いを学習する目的でもお使いいただけます。

操作方法

  1. 手動演奏機能

    鍵盤を押すと音が鳴り、鳴っている音が画面上部の音名表示エリアに表示されます。

  2. 自動演奏機能

    「自動演奏」ボタンを押すと、収録されている楽曲の中から1曲をランダムに選択し、自動で演奏します。自動演奏は「演奏中止」ボタンを押すか最後まで演奏されると止まります。

Sports Club Handstone EC Site HTML CSS JavaScript PHP MySQL

作品名: Sports Club Handstone EC Site

PHPとMySQLのデータベースを使用して、架空のプロテイン専門販売サイトを制作しました。

制作目的

工夫した点

遊び心こだわり満載の商品ラインナップで、SNSでバズること間違いなし！？

クーポンコード入力による割引機能、商品検索機能、購入バッジでカート内の商品数が一目で分かる機能など、ユーザー目線で欲しい機能を盛り込んでいます。

加えて、フォームの二重バリデーション、ログイン時のセッション再発行、SQLインジェクション対策、XSS対策、パスワードハッシュ化、CSRFトークンなどのセキュリティ対策を施しています。さらに悲観的ロックによる排他制御によりデータの整合性を保てるようにも設計されています。

私のイチ押し商品は「桃色♡肩重い」味！

利用方法

  1. 新規登録・ログイン

    「新規登録」ページにて任意のユーザーIDとパスワードを登録しユーザー登録を行います。

  2. 商品の閲覧

    気になる商品がありましたら、「カートに入れる」ボタンを押してカートに入れてみましょう。

  3. 購入手続き

    「購入する」ボタンを押すと、購入が完了します。
    ※ 架空サイトのため、実際に金銭が発生することはありません。

    クーポンコードを入力すると、割引を適用することができます。

    • SHIMAMOTO: ¥1,000OFF
    • HANDSTONE: ¥1,000OFF
    • ほか、その月のクーポン(詳しくはサイト内で案内しています)を使用することができます。

    クーポンは1ユーザーにつき1回のみ使用できます。
