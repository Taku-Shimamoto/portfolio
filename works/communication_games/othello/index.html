ゲーム内容

ゲーム説明

「質問力」×「オセロ」が夢の共演！

マスを取るためには、Yes / No クエスチョン(クローズドクエスチョン)と Yes / No で答えられない質問(オープンクエスチョン)を使い分け、お題を当てなければならない。

しかも、四隅はとても難易度の高い「水平思考クイズ」をクリアしなければ取ることはできない。

質問力・オセロの実力・水平思考力。あらゆる力を駆使し、勝利をつかむのはどちらのチームだ！？

主目的

  • オープン/クローズドクエスチョンを適切に用いてチーム内の意思疎通を図る(質問力)。
  • チームで協力して、盤面のどこに石を置くか、リソースをいつ使うか、などの合意を図りながら勝利を目指す(協調性、コンセンサス)。

遊び方

推奨人数

1チーム3人以上

所要時間

約90～120分

必要なもの

  • 本ゲームアプリ
  • ストップウォッチ
  • 水平思考クイズ10問程度
  • トランプまたはくじ引き(なくても十分に楽しめます)

手順

  1. 先攻と後攻を決め、チームカラーを決定します。
  2. 取りたいマスを選択し、タイルの部分をクリックするとお題が表示されます。

    このとき、解答はまだ見ないでください。

  3. チーム内で「回答役」を決めます。話し合いでもジャンケンでも、くじ引きなどでもお好きな方法で決めていただいて構いません。「回答役」以外の人は全員「質問役」になります。
  4. 「回答役」の方のみ、解答を見て確認します。
  5. 「質問役」の人たちは、オープン/クローズドクエスチョンを使いながら、2分以内に答えを当てます。

    ※クローズドクエスチョンに対して「回答役」が使える回答は「はい」「いいえ」「分かりません」「部分的にはい」「正解です」のみです。

    ※オープンクエスチョンは1回までです。誰がどのタイミングで使うのか、よく話し合って決めてください。オープンクエスチョンに対して「回答役」は答えに直接言及しない範囲でお答えください。

  6. 2分以内に正解できた場合はそのマスを取得して、手番を交代します。正解できなかった場合はそのまま手番を交代します。
  7. 2〜6を繰り返します。

水平思考クイズについて

  • 四隅はとても影響力が強いため、より難易度の高い「水平思考クイズ」に挑戦します。
  • 「水平思考クイズ」では、制限時間が4分になる代わりに、オープンクエスチョンが使えなくなります。

特別ルール

各チームは対局中3回まで、すでに置かれたマスから石を取り除くことができます(以下、「リソース」と表記します)。

  • 使える回数が限られている上、影響力がとても強いため、リソースを使う際はチームでよく話し合って決めてください。
  • リソースを使う際は リソースを使用→通常の手番 という形で行います。
  • リソースを使う場所は自分たちのチームが取ったマスでも相手チームが取ったマスでも選択できます。
  • リソースを使用した後の手番で、石を取り除いたマスを必ずしも取る必要はありません。
  • リソースを使用して空いたマスを取る場合、再度「お題」に挑戦し正解する必要があります。
  • Deleteキーを押すと石を取り除くことができる状態になります。Escキーを押すと解除されます。

作者コメント

ゲームを振り返って

このゲームを実施したとき、コミュニケーション活動(質問する、答える、意思疎通を図る、合意する)がとても活発に行われ、まさに「コミュニケーションの実践練習をゲームに落とし込んだ」と言えるものでした。

その一方で、ゲーム性の面で反省点や改善点も多く見られるものでもありました。

まず実施当初は、現在と異なる仕様でした。

  • 盤面5×5マス
  • 初期配置なし

一度の手番に時間がかかる関係上、盤面をなるべく大きくしすぎないことを意図してこのような仕様になったのですが、「挟んでひっくり返す」というオセロならではの要素がほとんど見られませんでした。

次に、「回答者」がお題に対して解答を準備して、ホワイトボードに記入するというやり方でした。「回答者」も味方であるため、必然的に正解しやすい解答を準備します。これがゲームの難易度を想定よりも低くしてしまい、数秒で解答にたどり着くケースも珍しくありませんでした。

最後に、リソースの使用回数です。実施当初はリソースを1回しか使えないルールでした。これに関しては後日実施したアンケートにて

  • 「1回しか使えないのは影響力が低い」
  • 「複数回使えたほうが、場が荒れて面白くなる」
  • 「序盤・中盤・終盤それぞれの駆け引きで使えると良い」
  • 「(複数回使えると)マスを取れないときに、パスの代替手段としてリソースを使えるメリットがある」

といった大変有益な意見をもらうことができました。これらの反省点や参加者からの意見を有志の間で検討した結果、現在のルール・仕様に至りました。

制作を振り返って

このゲームは初めてCSS変数を用いて制作を行いました。その恩恵はとても大きく、値が意味を持つことで、後で見たときに何を表す値なのかをすぐに理解できること、変更があっても直す場所を限定できるなどのメリットがありました。何よりこのゲームにおいて最も恩恵があると思ったのは「盤面生成」でした。

ゲームのルールや用途に応じて、盤面の大きさを自由に変更できる設計にしたいと考えました。そこで早速CSSでgridレイアウトを組み、マスの数を変数にします。JavaScriptでHTML生成をする際、このCSS変数がそのまま使えたら便利だなと思って調べてみると、そこで初めてgetComputedStyle()やgetPropertyValue()という方法があることを学びました。

今回はアキネータークイズとオセロを組み合わせたゲームとして実施しましたが、自由に盤面を変更できることによって、通常のオセロゲームとして遊びたい、難読漢字を当てるゲームにしたい、など遊び方を自由にアレンジすることができるようになりました。

もう一つ、新しい試みがあります。それはショートカットキーの導入です。操作をスムーズに行えるようにしたいと考え、簡易的なものではありますが、スペースキーまたはEnterキーでチーム切り替え、Deleteキーでマス削除、Escキーでマス削除状態のキャンセルをできるようにしました。

実装当時、ショートカットキーと紐づけた関数switchTeamColor()、startEmptyMode()、escapeEmptyMode()のイベントリスナーがバラバラに書かれていました。このとき、「3つくらいなら追えるかもしれないけど、数が多くなったときのためにイベントリスナーの一覧表のようなものが欲しい」と思い考えた結果、ラッパー関数を置いた現在の形になりました。 

document.addEventListener("keydown", (e) => handleKeydownEvents(e));
function handleKeydownEvents(e) {
    if (e.key === "Delete") startEmptyMode();
    if (e.key === "Enter" || e.key === " ") switchTeamColor();
    if (e.key === "Escape") escapeEmptyMode();
}

こうすることで、ショートカットキーとして何が使えるのかが一目で分かるだけでなく、キーを変えたり追加したりしたいとなったらこの周辺を触れば良いということが読み手に伝わります。

このように「入り口を揃える」という考え方は後の「ドラフトしりとリレー」において、「同じボタンでもモードやフェーズによって行う処理を変えたい」という場合に絶大な効果を発揮することになります。
